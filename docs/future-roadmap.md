# Future Roadmap

These are follow-up ideas that are no longer part of the completed post-MVP backlog.

For a more concrete feature wishlist, see [`docs/future-features.md`](future-features.md).

## Operations

- retry, dead-letter, and failure handling for derived work
- additional tracing or distributed observability
- long-term backup and retention automation

## Graph

- materialized subgraph projections beyond the current traversal cache
- graph freshness policies and projection invalidation strategies

## Retrieval

- embeddings and hybrid retrieval
- more advanced ranking across entities, relations, and events

## Insights

- cluster-level insights
- insight audit history and generation tracking is now part of the current baseline
- digest scheduling, retention, and push delivery can still be expanded later

## Extraction

- more source-specific adapters
- more LLM-assisted extraction for ambiguous inputs
- improved replay tooling for model outputs

## Clients

- mobile shell hardening
- optional web dashboard expansion

## Note

None of these are blocking for the current BrainIA backend, which now has a working shipped baseline and a completed post-MVP backlog phase.
