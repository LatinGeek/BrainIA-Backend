## Changes in this remediation

1. `src/storage/semantic-repository.ts` — `upsertEventSemanticAnchor` no longer deletes anchors.
   - Serializes per-event anchor writes with `pg_advisory_xact_lock(hashtext('event-semantic-anchor:<eventId>'))`.
   - Reads the existing primary `FOR UPDATE`.
   - Replaces a primary only when it is the **same domain and same governance generation**. Any cross-domain or cross-generation primary is preserved and returned as `{ applied: false, preservedPrimary: true }`.
   - The one-primary partial unique index is therefore never satisfied by implicit deletion of durable evidence.
2. `src/storage/semantic-resolver.ts` — new `applyEventAnchor` helper used by all eight anchor write sites.
   - When the anchor write is refused, the attempted resolution is enqueued as a pending `semantic_candidates` review path instead of silently overwriting or deleting the existing anchor.
   - Path application still reports `appliedPaths` for the graph relation that was applied; the anchor transition itself is deferred to review.
3. `src/storage/financial-transaction-repository.ts` — removed the unused `deleteFinancialTransactionsForEvent` helper, which contained a second, event-unscoped global orphan delete. No callers existed (`rg` across `src/`, `tests/`, scripts).
4. `src/storage/knowledge-fact-repository.ts` — removed the unused `replaceEventKnowledgeFacts` helper, which deleted every fact for an event regardless of extractor generation or fact type. Scoped replacement remains in `replaceClassificationFacts`.
5. `tests/v2-projections.test.ts` — new regression `B04 resolved semantic path preserves an unrelated-domain or older-generation primary anchor`:
   - Seeds a Health primary anchor from `older-generation`.
   - Runs `replaceSemanticProjection` scoped to a different Finance domain and asserts the Health anchor hash is unchanged.
   - Runs a resolved Finance path through `persistSemanticDecision`.
   - Asserts exactly one anchor still exists, still the Health domain, byte-identical, that the attempted transition is recorded as a `semantic_candidates` review path in the current generation, and that the path is counted as `reviewPaths` rather than `appliedPaths`.
6. Every anchor write site now returns the anchor outcome, so a deferred cross-domain/cross-generation transition is reported as `reviewPaths` (not a false `appliedPaths`) while the graph relation itself may still have been applied.
